Tutorial 6 consists of two parts covering different aspects of bioengineering modelling.

## Part A: Multiscale Modelling (MasoTalou & SharifzadehKermani)

This part covers multiscale modelling techniques using the VITAL multiscale toolkit, containerized with Docker.

### Resource Persons

| Name | Affiliation |
|------|-------------|
| **Alireza Sharifzadeh-Kermani** | Auckland Bioengineering Institute, University of Auckland |
| **Gonzalo Maso Talou** | Auckland Bioengineering Institute, University of Auckland |

### Overview

The multiscale modelling tutorial includes three main components:

- **CCO** — Constrained Constructive Optimization for vascular network generation
- **MicrovascularModelling** — Python-based scripts for 1D hemodynamic simulation and homogenisation
- **VItA** — Additional tutorial materials

The tutorial walks through a full pipeline: generating vascular trees, running hemodynamic simulations, and quantifying equivalent resistance. It includes two exercises on statistical analysis and noise sensitivity.

### Prerequisites

- Docker installed on your system ([Installation Guide](/prerequisites/docker))
- Basic familiarity with command line operations
- At least 8GB of available RAM
- (Optional) ParaView for visualizing simulation results ([Installation Guide](/prerequisites/paraview))
