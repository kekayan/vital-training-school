This tutorial covers multiscale modelling techniques using the VITAL multiscale toolkit. The tutorial is containerized with Docker for easy setup and reproducibility.

## Overview

The multiscale modelling tutorial includes three main components:

- **CCO** - Constrained Constructive Optimization for vascular network generation
- **MicrovascularModelling** - Python-based scripts for microvascular modelling
- **VItA** - Additional tutorial materials
