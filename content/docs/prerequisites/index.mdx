## System Requirements

- **Operating System**: Ubuntu 22.04+, macOS 12+, or Windows 10/11
- **RAM**: Minimum 8GB (16GB recommended)
- **Storage**: At least 20GB free space
- **Internet**: Stable connection for downloading images
