This tutorial uses **Circulatory_Autogen**, a software designed for generating and calibrating computational models (CellML or 1D finite volume), integrated with OpenCOR and Jupyter Lab.

## Overview

- **Circulatory model generation** — Using Circulatory_Autogen to generate computational circulatory models
- **Model calibration** — Calibrating CellML and 1D finite volume models
- **OpenCOR integration** — Launching and scripting OpenCOR from Jupyter notebooks

## Key Files

| File | Description |
|------|-------------|
| `tutorial_2_5_test.ipynb` | Main tutorial notebook |
| `test_opencor.ipynb` | OpenCOR verification notebook |
| `circulatory_autogen/` | Circulatory_Autogen repository (cloned separately) |
